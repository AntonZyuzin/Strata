- Статус: Принято (2026-10-19, по делегированию владельца); подтверждается спайком 5 ([15 §7](../15-architecture.md), [16 §3.2](../16-roadmap.md)). - Связано: [05-domain-model.md](../05-domain-model.md) (§4.2, §12, §13), [06-canvas-ux.md](../06-canvas-ux.md) §13.2, [07-design-system.md](../07-design-system.md) (§3.2, §8.4), [10-storage-sync-collab.md](../10-storage-sync-collab.md) (§2.4, §8.4, §9.2, §11, §13), [12-mcp-ai.md](../12-mcp-ai.md) §7, [13-interop.md](../13-interop.md) §2.8, [14-nfr.md](../14-nfr.md), [15-architecture.md](../15-architecture.md) (§2.3, §7, §8.4, §8.5), [16-roadmap.md](../16-roadmap.md) (§5.2, §8.2), [ADR-0003](0003-sync-engine.md), [ADR-0004](0004-app-shell.md), [ADR-0005](0005-rendering.md), [ADR-0007](0007-text-editor.md); исследования [R5](../research/R5-board-engine.md) (главное), [R3](../research/R3-crdt-sync.md), [R2](../research/R2-obsidian-format.md), [R4](../research/R4-app-shell-rendering.md)

## Контекст

Требования:
- ✅ E1: «Excalidraw подходит, если позже можно будет дорабатывать инструменты».
- ✅ C2: у ноды одно содержимое. Доска может содержать небольшие виджеты коротких заметок и to-do; полноценный текст — только в заметках.
- ✅ A1: Strata — ещё и база для сбора текстов и изображений; доски нужны для референсов.
- ✅ J2: совместная работа в реальном времени. ✅ C8: `[[ссылки]]` создают нити — и из текста на доске.
- ✅ N1: документ доски грузится только при открытии, картинки — по видимой области.
- ✅ K1: AI кладёт картинки на доски ([12](../12-mcp-ai.md) §7).
- ✅ O1: импорт готовой базы Obsidian — в первой версии, а значит, и досок `.excalidraw.md` ([13](../13-interop.md) §2.8).
- ✅ I1, I2: туманный фон и ретро-окна; доска живёт в окне содержимого поверх холста ([07](../07-design-system.md) §8.4).
- Бюджеты [14](../14-nfr.md): открытие доски B-2k — первый кадр ≤ 1 с (NFR-30), прирост памяти ≤ 1,5 ГБ (NFR-52), доска не грузит чужое (NFR-84), биндинг сходится (NFR-123).
- Источник правды — Loro ([ADR-0003](0003-sync-engine.md)); UI — React 19 ([ADR-0004](0004-app-shell.md)).

Факты ([R5](../research/R5-board-engine.md)):
- Excalidraw — MIT. Стабильный 0.18.0 вышел 2025-03-11, 0.18.1 (2026-04-20) — только патч безопасности; о 0.19 нигде нет ни слова. Всё новое — в снапшотах `next` (`0.18.0-43a92e6` от 2026-10-12, 45 снапшотов за 2026 год), и там уже переименованы методы API (§1–§2).
- Только в `next` есть `ui={false}`, поток дельт `onIncrement`, `imageOptions`, `activeTool` под управлением хоста и элемент `stickynote`. В 0.18.1 картинки жёстко ужимаются до 1440 px и 4 МБ (§2, §7).
- Своих типов элементов и шрифтов в публичном API нет. Свои инструменты (`custom`), поле `customData` и React-виджеты через `renderEmbeddable` — есть (§3, §5).
- Excalidraw держит все добавленные файлы в памяти как `dataURL` и не умеет их выгружать (§7).
- Слияние в Excalidraw — LWW по элементу: побеждает больший `version`, при равенстве — меньший `versionNonce`; z-порядок задаёт дробный `index` (§10, [R3](../research/R3-crdt-sync.md) §9). Готового биндинга к Loro нет: `loro-excalidraw` — «proof of concept… not optimized for production» на Excalidraw 0.17 (§10).
- tldraw с 4.0 требует ключ лицензии в продакшне (§13).

## Решение

**Движок досок — Excalidraw (MIT) на закреплённом снапшоте `next` за адаптером `BoardEngine`. Сцена хранится в документе содержимого `content/{id}`: элементы — в `LoroMap`, LWW на элемент. Хром доски, виджеты и хранение картинок — свои.**

1. **Версия.** Точный снапшот `next` без `^` — сейчас `0.18.0-43a92e6`. Обновление снапшота — отдельная задача с прогоном тестов биндинга. Если стабильный 0.19 выйдет до релиза MVP, переходим на него. ☑ Q-15-5: разрабатываем на точном снапшоте `next` за адаптером; запасной путь — 0.18.1 с биндингом через `onChange` (альтернатива 5).
2. **Адаптер `BoardEngine`** — в пакете `board`, единственном, который импортирует `@excalidraw/excalidraw` ([15](../15-architecture.md) §2.3):

   ```ts
   interface BoardEngine {
     mount(container: HTMLElement, doc: DocHandle): void;
     setTool(tool: BoardTool): void;
     insertWidget(kind: 'note' | 'todo'): void;
     insertImage(sha256: string): void;
     exportThumbnail(): Promise<Blob>;
     destroy(): void;
   }
   ```

   Всё специфичное для Excalidraw — внутри: переименования API, `customData`, `reconcileElements`, подъём схемы при открытии доски ([10](../10-storage-sync-collab.md) §13). Остальная Strata видит только адаптер и Loro-документ.
3. **Окно доски** — ретро-окно Strata ([06](../06-canvas-ux.md) §13.2, [07](../07-design-system.md) §8.4):
   - Excalidraw с `ui={false}`: встроенные тулбар, меню и панели не рисуются. Свой пиксельный тулбар задаёт инструмент через `activeTool` под управлением хоста (спайк 5: без него Excalidraw после фигуры сам возвращается к «Выбору» и расходится с тулбаром), панель свойств вызывает `updateScene`;
   - тема `light` (в `dark` Excalidraw инвертирует каждый цвет элемента), `viewBackgroundColor: "transparent"` — за доской туманный фон Strata;
   - по умолчанию `roughness: 0`, цвет линии — бумага, палитра Strata — своя полоса цветов окна (07 §8.2; `colorTopPicks` при `ui={false}` не показывается); шрифт — Excalifont или Nunito, у обоих есть кириллица. ☑ Q-15-6: по умолчанию строгий вид; ретро — в рамке, тулбаре и виджетах; пиксельный шрифт на холсте доски — этап 2 через мягкий форк, если понадобится;
   - шрифты и ассеты — в сборке через `EXCALIDRAW_ASSET_PATH`, а не с `esm.sh`; источник `esm.sh`, который Excalidraw всё равно дописывает в каждый шрифт, вырезается (спайк 5); `aiEnabled={false}`, без каталога библиотек, без внешних iframe (NFR-84);
   - клавиши: `handleKeyboardGlobally={false}`. Strata в фазе capture перехватывает только `U`, `Tab`, `Esc`, `F6`, `Ctrl+W`; остальные буквы — инструменты Excalidraw (`L` здесь — линия).
4. **Виджеты** — свои React-компоненты в элементах `embeddable`:
   - элемент: `{type: "embeddable", link: "strata://<workspace-id>/widget/<board-id>/<widget-id>", customData: {strata: {widget, v}}}` — формат ссылки по грамматике глубоких ссылок ([05](../05-domain-model.md) §9.4), `<board-id>` — ID ноды-доски. `validateEmbeddable` пропускает только такие ссылки, `renderEmbeddable` рисует компонент вместо `<iframe>`;
   - «Заметка»: в просмотре — статичный HTML из Markdown, при правке монтируется лёгкий режим редактора на `LoroText` ([ADR-0007](0007-text-editor.md)). `[[ссылки]]` дают нити от доски с происхождением `text`;
   - «To-do»: пункты в `LoroMovableList`, текст пункта — `LoroText`. В MVP — простые галочки, а не задачи Strata (☑ Q-15-9); «превратить пункт в ноду-задачу» — действие этапа 2. Задачи и подзадачи Strata — сети класса «Задача» (✅ Q-05-1, [05](../05-domain-model.md) §4.3), пункт виджета ими не является;
   - геометрия, слой и фрейм виджета лежат в `elements`, содержимое — в `widgets` и сливается посимвольно;
   - нативный `stickynote` — для быстрых пометок: рисуется на холсте доски и попадает в экспорт, но сливается LWW;
   - перед экспортом и миниатюрой виджеты временно заменяются текстом и прямоугольниками через `convertToExcalidrawElements`.
5. **Картинки — через хранилище ассетов** ([10](../10-storage-sync-collab.md) §11):
   - `generateIdForFile` считает SHA-256 оригинала и в том же колбэке кладёт оригинал в хранилище. У новых картинок `fileId` совпадает с ключом ассета; карта `files` сопоставляет с SHA-256 и чужие `fileId` — SHA-1 из Obsidian;
   - Excalidraw получает рабочую копию — WebP до 2048 px по длинной стороне, настройкой пространства до 4096 — через `imageOptions`;
   - `addFiles` вызывается только для картинок в видимой области с запасом, остальные догружаются по прокрутке; оригинал открывается в просмотрщике по двойному клику. ☑ Q-15-7: при сотнях картинок на доске — патч выгрузки или свой рендер (условия перехода ниже).
6. **Хранение** — `content/{boardNodeId}`, грузится только при открытии доски ([10](../10-storage-sync-collab.md) §2.4):

   ```ts
   meta:     LoroMap  { schema, engine: "excalidraw@0.18.0-43a92e6", viewBackgroundColor, gridSize }
   elements: LoroMap<elementId, ExcalidrawElementJSON>   // LWW на элемент, isDeleted — tombstone
   files:    LoroMap<fileId, { sha256, mime, w, h, created }>
   widgets:  LoroMap<widgetId, LoroMap { kind, text?: LoroText, items?: LoroMovableList }>
   ```

   Элемент лежит в карте целиком: так слияние совпадает с семантикой Excalidraw и не собирает элемент из полей разных авторов. Замер [R5](../research/R5-board-engine.md) §9 на 1 000 элементов: снапшот 290 КБ, жест на 20 элементов — 5,3 КБ, открытие — 110 мс.
7. **Биндинг Excalidraw ↔ Loro**:

   | Направление | Как |
   |---|---|
   | Локальное → CRDT | `onIncrement`: долговременная дельта → `elements.set` для изменённых элементов, один коммит на жест. Эфемерная (перетаскивание, ресайз) → `EphemeralStore`, не чаще 30 Гц. Каждое `pointermove` в CRDT не пишется |
   | CRDT → локальное | Изменённые ключи → `reconcileElements` по `version` и `versionNonce`; элемент, который сейчас редактируется, не перетирается → `updateScene({captureUpdate: NEVER})`, удалённые правки не попадают в локальный undo |
   | Сходимость | 💡 Итоговое значение — то, что в Loro. Порядок Loro не знает про `version`, поэтому он и `reconcileElements` могут выбрать разных победителей. Если после слияния у клиента остался нередактируемый элемент новее значения в CRDT, биндинг записывает его в CRDT заново. Проверяет спайк 5 |
   | Курсоры и выделения | `onPointerUpdate` → эфемерный канал → `updateScene({collaborators})` |
   | Отмена | Сцена — встроенный undo Excalidraw; текст и пункты виджетов — UndoManager Loro, пока фокус внутри виджета ([10](../10-storage-sync-collab.md) §9.2) |

8. **Импорт из Obsidian** — MVP: `.excalidraw.md` → нода-доска. Распаковка LZString, элементы как есть, `## Embedded Files` → ассеты. Парсер пишем сами по формату. Лицензия плагина Obsidian Excalidraw (AGPL-3.0) с лицензией Strata теперь совместима ([ADR-0009](0009-license.md)), но код плагина не берём: он на TypeScript под API Obsidian, а разборщик живёт в Rust-ядре ([13](../13-interop.md) §2.8, §8). ☑ Q-13-7: экспорт — MVP+ 1.2, карточка `.md` и сцена `.excalidraw`; этап 2 — `.excalidraw.md` в зеркале без приёма правок; приём правок досок — после этапа 2 по запросу.
9. **Доска от агента** (MVP+ 1.1, вместе с MCP, [16](../16-roadmap.md) §5.2). Доменные операции `board.addImage`, `addNote`, `addTodo` в Rust-ядре пишут валидные элементы — с `seed`, `version`, `versionNonce` и дробным `index` — в тот же документ; клиенты получают их как удалённые правки. Миниатюру рисует только клиент: ядро без DOM сцену не отрисует, до открытия доски превью помечено `thumbnail_stale` ([12](../12-mcp-ai.md) §7.5).

## Альтернативы

1. **tldraw** 5.5.2 ([R5](../research/R5-board-engine.md) §13).
   - Плюс: лучшая расширяемость: кастомные фигуры с React, инструменты на `StateNode`, `TLAssetStore`, который отдаёт уменьшенную копию по масштабу экрана, темы в v5.
   - Минус: с 4.0 продакшн требует ключ лицензии; без ключа SDK через 5 с перестаёт рисовать редактор. Ключ привязан к доменам, а у self-hosted серверов домены произвольные. Хобби-ключ выдаётся по усмотрению, с водяным знаком и телеметрией. Про open source tldraw пишет прямо: «you and your downstream users will require their own trial, commercial, or hobby license».
   - Минус: tldraw sync — свой сервер на JS под той же лицензией, вторая система синхронизации рядом с Loro.
   - Итог: лицензия tldraw запрещена ([15](../15-architecture.md) §8.4), в том числе транзитивно через MIT-«starter kits».
2. **BlockSuite** — edgeless-холст AFFiNE ([R5](../research/R5-board-engine.md) §14). Лицензия MPL-2.0 в отдельном репозитории, MIT — в монорепо AFFiNE. Завязан на Yjs и модель блоков AFFiNE, а у Strata — Loro. Пакеты `@blocksuite/*` не обновлялись с 2025-07-01, README — «currently in its early stage».
3. **Свой редактор на PixiJS** ([R5](../research/R5-board-engine.md) §15).
   - Плюс: единый вид с холстом сетей (туман, гравюра, пиксельные шрифты), одна навигация и хоткеи, полный контроль памяти под картинки.
   - Минус: 3–6 человеко-месяцев до подмножества Excalidraw (оценка, не проверено): стрелки с привязками, текст с IME, undo в совместной работе, экспорт. Риск для MVP; совместимость с `.excalidraw.md` пришлось бы писать отдельно.
   - Итог: этап 4 по необходимости — на той же схеме элементов ([16](../16-roadmap.md) §8.2).
4. **Konva, Fabric.js и похожие** — Konva 10.8.0 и Fabric.js 7.4.0, обе MIT ([R5](../research/R5-board-engine.md) §14). Это кирпичи, а не доска: стрелки с привязками, фреймы, совместную работу и undo пришлось бы писать самим, а рядом с PixiJS появился бы второй 2D-рендер. Leafer UI, Plait/Drawnix, Quickdraw, Penpot и draw.io отпадают по той же или своей причине: второй рендер, нет совместной работы в реальном времени, версия 0.x или целая отдельная платформа.
5. **Стабильный Excalidraw 0.18.1.**
   - Плюс: API заморожен.
   - Минус: нет `ui={false}` — свой UI только CSS-переопределениями; нет `onIncrement` — биндинг через дифф всей сцены в `onChange`; картинки до 1440 px; нет `stickynote` и управляемого `activeTool`.
   - Итог: запасной путь, если `next` сломает биндинг и это не чинится за адаптером.
6. **Форк Excalidraw с первого дня** — по образцу `@zsviczian/excalidraw` 0.18.143 (MIT), на котором живёт плагин Obsidian ([R5](../research/R5-board-engine.md) §5).
   - Плюс: свой шрифт на холсте, выгрузка файлов, виджеты без клика-активации.
   - Минус: +2–4 недели на патчи (оценка) и постоянная работа вслед за `master`.
   - Итог: не сразу; условия перехода — ниже.

## Последствия

- ➕ Доска уровня Excalidraw в MVP за 4–7 недель (оценка [R5](../research/R5-board-engine.md); ориентир объёма, а не срок — ✅ R2: B3) — с совместной работой, виджетами и картинками из хранилища Strata.
- ➕ Формат — схема элементов Excalidraw плюс `customData.strata` и `widgets`. Он не привязан к компоненту, совпадает со сценой `.excalidraw.md` и переживёт смену движка.
- ➕ Импорт досок из Obsidian — прямой перенос сцены.
- ➖ API `next` ломается между снапшотами: `excalidrawAPI` → `onExcalidrawAPI`, `scrollToContent` → `setViewport`. Снижаем: точная версия, адаптер, тесты биндинга (NFR-123), запасной путь на 0.18.1.
- ➖ Виджеты живут в DOM-слое: всегда поверх рисунка, первый клик только активирует, после первого показа остаются смонтированными, в экспорт не попадают, пиксельный шрифт в них мылится при дробном зуме. Снижаем: статичный режим просмотра, редактор монтируется только при правке, конвертация перед экспортом, текст виджетов — Golos Text ([07](../07-design-system.md) §3.2).
- ➖ Память под картинки: Excalidraw их не выгружает. Снижаем: рабочие копии и ленивое `addFiles`; бюджет — NFR-52.
- ➖ LWW на элемент: при одновременной правке одной подписи одна версия теряется. Длинный текст — в виджетах с посимвольным слиянием.
- ➖ История растёт на размер элемента при каждой правке: в среднем 650 байт, у `freedraw` — килобайты. Снижаем: коммит на жест, эфемерный канал, shallow-снапшоты и чистка tombstones на сервере; срок хранения tombstones привязан к окну офлайна. ☑ Q-15-8: свободное рисование есть, перо с давлением — после MVP.
- ➖ Два стека отмены — Excalidraw в сцене и Loro в виджетах. Путают ли они пользователя, проверяет спайк 5.
- ➖ Стиль холста доски ограничен: две темы, зашитые шрифты. Ретро — в рамке окна, тулбаре и виджетах; пиксельный шрифт на холсте доски — только через форк.
- ➖ Rust-ядро пишет элементы Excalidraw без JS и должно следить за схемой при каждом обновлении снапшота. ☑ Q-12-10: в MVP+ 1.1 агент только добавляет элементы; правка и удаление элементов, созданных агентом, — этап 2 через журнал.
- ➖ `stickynote` не понимают 0.18.1 и excalidraw.com на старой версии: `restore` его выбрасывает. При экспорте во внешние форматы стикер становится прямоугольником с текстом.

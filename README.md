# Strata

Нодовая система для заметок и задач в ретро-пиксельном стиле: типизированные ноды, Houdini-подобная работа с графом, 3D «звёздная карта», MCP, совместимость с Obsidian, локальная работа или свой сервер.

Статус: этап 0 — каркас и спайки ([дорожная карта](docs/16-roadmap.md)). Документация — [docs/README.md](docs/README.md).

## Сборка

Нужны Rust 1.97 (`rust-toolchain.toml`), Node 22 и pnpm 10.

```sh
pnpm install
pnpm dev               # интерфейс в браузере
pnpm desktop:dev       # десктоп-приложение (Tauri 2)
cargo test && pnpm test
```

Готовые сборки для macOS, Windows и Linux — в артефактах последнего запуска CI (вкладка Actions). Сборки пока не подписаны: на macOS открыть через контекстное меню «Открыть», на Windows — «Подробнее → Выполнить в любом случае».

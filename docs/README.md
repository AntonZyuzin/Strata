## Обозначения

| Метка | Значение |
|---|---|
| ✅ **Решено** | Подтверждено ответами владельца продукта ([02](02-questions.md), ссылка на ответ: «✅ C3») или требованием брифа ([00](00-brief.md)) с пометкой «✅ бриф» |
| 💡 **Предложение** | Значение по умолчанию, ждёт подтверждения |
| ❓ **Вопрос** | Нужен ответ. ID вида `Q-05-1` (номер документа и номер вопроса). Все вопросы собраны в [17-open-questions.md](17-open-questions.md) |

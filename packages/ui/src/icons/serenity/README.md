# Значки SerenityOS

Значки Хрома в духе Windows 98 (решение владельца 2026-10-24, 07 §6.2). Источник — `Base/res/icons/16x16` репозитория [SerenityOS/serenity](https://github.com/SerenityOS/serenity), коммит `e20af9124413310edcb13ffb59e867cb6a73995b`. Лицензия — BSD 2-Clause (`LICENSE` рядом), совместима с AGPL-3.0-or-later; текст показывают «Благодарности».

Файлы скопированы без изменений. Чёрные контурные значки (`undo`, `redo`, `plus`, `window-close`) Хром рисует маской цветом текста, остальные — как есть, с целочисленным масштабом.

Песочные часы задачи (`../hourglass.png`), доска (`../board.png`) и дом основного размещения (`../home.png`, контурный, как `undo`) нарисованы для Strata в той же манере; их лицензия — лицензия репозитория. Доска заменила `app-pixel-paint`: полупрозрачные карандаши без контура выбивались из набора (владелец, 2026-10-24).

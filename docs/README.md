# Документация Gexogon

Видимое имя продукта — Gexogon (✅ Q-16-15, 2026-10-25); в документах до этой даты, в коде, пакетах, крейтах и формате `.strata.zip` — прежнее рабочее имя Strata.

Этап: реализация, этап 0 (каркас и спайки). Код пишет Claude по [дорожной карте](16-roadmap.md); календарных сроков нет, прогресс — по вехам, каждая веха заканчивается сборкой, которую владелец проверяет на macOS и Windows по короткому чек-листу (✅ R2: B2, B3). Документы остаются источником правды: расхождение с кодом сначала правится здесь.

Раунд 2 ответов получен 2026-10-19: все вопросы [17](17-open-questions.md) решены. Основные платформы — macOS и Windows, Linux собирается в CI и проходит автотесты (✅ R2: Q-15-1). Интерфейс — русский и английский с MVP (✅ R2: Q-07-1). Лицензия — AGPL-3.0-or-later на весь репозиторий; шрифты, иконки и прочие ассеты — под своими лицензиями (☑ R2: B4, Q-11-7).

| Метка | Значение |
|---|---|
| ✅ **Решено** | Подтверждено ответами владельца продукта ([02](02-questions.md), ссылка на ответ: «✅ C3»; раунд 2 — [17](17-open-questions.md), «✅ R2») или требованием брифа ([00](00-brief.md)) с пометкой «✅ бриф» |
| ☑ **Принято** | Решение по делегированию владельца (раунд 2, 2026-10-19); действует, пока владелец не попросит иначе. Ссылка на вопрос: «☑ Q-05-2» или «☑ R2» |
| 💡 **Предложение** | Значение по умолчанию, предложенное в документе. С 2026-10-19 считается принятым (правило ниже) |
| ❓ **Вопрос** | Нужен ответ. ID вида `Q-05-1` (номер документа и номер вопроса). Все вопросы собраны в [17-open-questions.md](17-open-questions.md) |

Правило: 💡 предложения в документах с 2026-10-19 считаются принятыми, кроме чисел и порогов, которые подтверждаются спайками и бенчмарками. Такие числа помечаются «проверяется спайком N» или ссылкой на NFR из [14](14-nfr.md). «R2» в метках «✅ R2» и «☑ R2» — раунд 2 ответов, не исследование [R2](research/R2-obsidian-format.md).

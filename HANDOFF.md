Состояние на 2026-10-25, коммит — `git log -1`. Видимое имя продукта — **Gexogon** (✅ Q-16-15); репозиторий, код, пакеты и формат файлов — `strata`. ## Что это

Gexogon (рабочее имя — Strata) — приложение для заметок и проектов на нодах: баблы-гексагоны на холсте, нити между ними, работа с сетью как в Houdini (Tab-меню, вставка в нить, встряхивание, нож), задачи со сроками и ответственными, звёздная 3D-карта. Ретро-пиксельный интерфейс в духе Windows 98 со значками SerenityOS. Стек: Tauri 2, ядро на Rust поверх Loro и SQLite (в браузере — то же ядро в WASM), SPA на React 19 + Vite, холст на Pixi 8. Интерфейс на русском и английском. Владелец продукта проверяет сборки на macOS (M1) и Windows.

## Сборка и проверка

Нужны Node ≥ 22 и pnpm 10 (`corepack enable`), Rust 1.97 из `rust-toolchain.toml` с целью `wasm32-unknown-unknown`, `wasm-pack`.

```sh
pnpm install
pnpm wasm                      # ядро и раскладки в WASM: packages/backend/pkg, packages/layout/pkg
pnpm lint && pnpm typecheck && pnpm test
cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test
pnpm --filter @strata/ui e2e   # Playwright; браузеры — pnpm exec playwright install
pnpm dev                       # UI в браузере на ядре-WASM, http://localhost:5173
pnpm desktop:dev               # десктоп
```

- После правки ядра на Rust пересобрать WASM (`pnpm --filter @strata/backend build`), иначе браузер и e2e работают со старым ядром и отвергают новое.
- E2E ходят на `vite preview` порта 4173 и переиспользуют запущенный сервер: после правок UI — `pnpm --filter @strata/ui build`.
- Хук для e2e — `window.__strataWs` (холст, граф, `settled()`), в прототипе — `window.__strataProto`.
- Тест биндинга доски изредка падает по тайм-ауту под нагрузкой параллельного e2e; отдельно проходит.
- Процессы — по PID, не `pkill -f`.

**macOS (машина владельца).**
- `pnpm wasm` падает с системным `ar`: `rustup component add llvm-tools` и `AR_wasm32_unknown_unknown` = `~/.rustup/toolchains/1.97.0-aarch64-apple-darwin/lib/rustlib/aarch64-apple-darwin/bin/llvm-ar`.
- Локальный конфиг e2e с Chromium из кэша Playwright — вне git (`.git/info/exclude`).
- Диск почти полон: `target/` растёт быстро, безопасно освобождать место через `rm -rf target/debug`.

**Облачная сессия (Linux-контейнер).**
- `wasm-pack` нет, а скачивать бинарники с GitHub среда не даёт: `cargo install wasm-bindgen-cli --version 0.2.129 --locked` и `cargo install wasm-pack --version 0.13.1 --locked` (около 3 минут), затем `pnpm wasm`.
- Playwright 1.56 ждёт Chromium 1194, а в `/opt/pw-browsers` лежит 1243 с другими путями. Каталог в scratchpad: `chromium-1194` → ссылка на `chromium-1243`; `chromium_headless_shell-1194/chrome-linux/` — ссылки на файлы `chrome-headless-shell-linux64/` плюс `headless_shell` → `chrome-headless-shell`, файлы `INSTALLATION_COMPLETE` и `DEPENDENCIES_VALIDATED`; затем `PLAYWRIGHT_BROWSERS_PATH=<каталог> pnpm exec playwright test --project=chromium` при запущенном `pnpm preview --port 4173`. WebKit там не скачать — он проверяется в CI.
- Скрипты скриншотов — в scratchpad (`require('playwright')` из предустановленного Playwright работает из любой папки).
- Под 4 воркерами e2e в контейнере изредка не успевает «prototype Chrome is locale-independent @2x» (программный WebGL); отдельно проходит.
- Там же падает e2e «.strata.zip … comes back as a copy» (имя файла `download`); в CI проходит — не регрессия.

## Ревью изменений 1B (2026-10-24)

Три независимых ревьюера прошли изменения с `407c39a` по `937fdf8` (значки, ADR-0010). Каждое замечание проверено по коду. Не ошибка: портфель у проекта — владелец сам выбрал его.

**Код — закрыто** (слиянием ветки коллеги и следующим за ним коммитом, у каждого исправления — тест):

- редактор описания пересоздавался на каждый рендер — панель ключуется по ноде;
- `Escape` в полях панели записывал вместо отката, в «Новая подзадача» создавал задачу;
- дуга прогресса задачи, проекта и папки на холсте не менялась после галочки, подзадачи или нити — `followFolds` перечитывает свёртки из ядра после каждого шага;
- оптимистичные галочки не сбрасывались после отмены;
- превью-чеклист проекта терял задачи в цикле нитей и папку, к которой ведёт нить от задачи (тест `a_project_preview_shows_what_its_roll_up_counts`);
- ссылка без схемы отвергалась — `linkOf` дописывает `https://`;
- ассет без `mime`: холст и панель читают тип одинаково, тип файла без типа — по первым байтам (`sniffMime`);
- поля задачи и ответственных на нодах чужого вида теперь можно очистить;
- панель ассета показывала файл прежнего ассета, у `core.asset` не было `catch`;
- шаг отмены галочки подзадачи подписан её именем, смена файла — «файл», а не «картинка»;
- подсказки значков ассета — через `@strata/i18n`;
- Tab-меню обрезало «Ассет»; поясняющий тост «Окно списка — следующий шаг 1B»;
- тесты: комментарий `sync.test.ts` про заметку; проверка «в задачу не ныряют» ловит теперь и ошибку страницы, и «Открыть» в меню; перетаскивание ссылки на холст покрыто e2e.

**Документы после ADR-0010 — закрыто:** 05, 06, 07 (§6.2, Q-07-21), 09, 10, 12 (контракт MCP), 13, 17, глоссарий, трассировка (BR-0.6, ANS-Q-05-1.1), 03-vision; в ADR-0002 и ADR-0006 — пометка «Уточнено ADR-0010».

## Открытые вопросы владельцу

- **Q-07-22** — срок словом на холсте, кольцо 1u у «скоро», точка в «Нодах»: сделано по предложению, ждёт подтверждения.
- Заголовок списка нод слева — «Ноды»: «Слои» владельцу не подошло; если не подойдёт и это — «Содержимое», «Структура».
- Q-07-18 (кегль при 125 и 150 %), Q-07-19 (фото-пресеты фона) — со спайка 9.
- **Q-06-24** — PDF в просмотрщике на Linux и постранично: 💡 pdf.js в 1C, если нужно.

## Решения владельца по интерфейсу

Владелец назвал прежний UX «абсолютно непонятным»; с тех пор правила такие, и их нарушение он замечает сразу:

- Максимально функционально, без поясняющих строк и лишних элементов: объяснение — только в `title` и меню. Значки вместо текстовых кнопок, меню — по ПКМ, двойной клик — «открыть».
- **Один факт — один раз на экране.** Не повторять имя полем под заголовком, ссылку — ссылкой над полем, заголовок группы — над единственной группой, заголовок страницы — если его уже говорит вкладка. Строку пути и кнопку «Выше» убрали: выход из сети — `U`, где ты — видно в «Нодах».
- Оболочка как Figma или ретро-браузер: главная на весь экран без кнопки закрытия; в шапке логотип (→ главная), импорт, экспорт, отмена, повтор, звёздная карта, вкладки, «+» после последней вкладки, «Настройки» справа. Неактивная вкладка той же формы, только серая.
- «Ноды» — во всю высоту слева, пространство само не строка; панель свойств — во всю высоту справа.
- **Воздух как в Figma.** Панель: по бокам 16u, сверху и снизу секции 14u, между полями 8u, поля высотой 28u; цвет и значок — блоками на всю ширину, шаг 6u. Плотно прижатое владелец называет «зажатым».
- **Выравнивание.** Элементы в строке: общие верх, низ и середина. Значки в столбце — на одной вертикали. Проверять замером по пикселям на скриншоте, а не на глаз.
- **Пиксельная графика — только в целое число раз:** значки 16u, 24u (втрое на DPR 2), 32u; шрифт интерфейса 11 px, заголовки окон — 22 px. «Чуть меньше» — значит ×1,5 от 16, а не произвольный размер.
- Заголовки панелей — крупные и читаются как заголовки; заголовки секций — обычным регистром цветом текста.
- Один акцент — салатовый. Цветная обводка ноды — 6u. Нода — гексагон «остриём вверх» (✅ Q-07-23), нити и кружки концов — на углах, нити — плавные S-кривые (стиль на сеть: прямая / Безье / кинетическая).
- Путь — в левом нижнем углу холста, корень — только значок (имя во вкладке) (✅ Q-06-25). Внешние сервисы и переключатели «включить функцию» без нужды не вводить: превью ссылки — всегда (✅ Q-13-16).
- Значки — SerenityOS в духе Windows 98; задача — песочные часы, проект — портфель, папка — папка.
- Текст описания в панели не крупнее заголовков, без подсказок-инструкций.
- Каждое изменение UI сначала проверить снимками: RU и EN, DPR 1 и 2. Владелец присылает скриншоты-замечания — отвечать делом и показывать результат.

## Как работать

- Ядро модели — `docs/05-domain-model.md`. Новое решение сначала меняет модель и оформляется ADR (`docs/adr/`); вопрос — с ID `Q-<док>-<номер>` в документе и в `docs/17-open-questions.md`. Термины — строго по `docs/glossary.md`.
- Каждое правило модели покрыто тестом в `crates/strata-core/src/tests.rs`; каждое новое окно или панель — e2e-тестом раскладки (RU и EN, DPR 1 и 2, Chromium и WebKit).
- Видимые строки — только через `@strata/i18n`, в оба каталога. Размеры Хрома — в пиксельных единицах `calc(k * var(--u))`.
- Ассеты — только с источником и лицензией; значки SerenityOS — с того же коммита, что в `packages/ui/src/icons/serenity/README.md`; всё поставляемое — в «Благодарностях».
- Перед пушем: `cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test`, `pnpm lint && pnpm typecheck && pnpm test`, e2e в Chromium.
- Скриптовые правки длинных документов проверять по `wc -l` и `git diff --stat`: однажды замена одной строки обрезала `docs/07-design-system.md` наполовину (восстановлен в `83f0fba`).

## Кратко

- ✅ **Открыть и сохранить без правок — те же байты** на всех 60 файлах V-synth: OFM, frontmatter, callouts, сноски, LaTeX, таблицы, HTML, CRLF, BOM, смешанные переводы строк, NBSP, не-NFC (ADR-0007 п. 7, правила 1–3).
- ✅ **Два клиента сходятся** после 40 раундов случайных правок через `loro-codemirror`; **отмена — только своих правок** (10 §15 п. 1).
- ✅ **Заметка на 1 МБ открывается за 47 мс** (NFR-29 ≤ 1 с); **символ — 9,6 мс p95** работы (NFR-33 ≤ 16 мс). M1, Chromium.
- ✅ `[[Имя]]` в тексте — нить заметка → нода (05 §8.2 п. 4, ✅ C8); убрали ссылку — нить ушла. Такие нити — производные (`system`, 05 §11) и не попадают в отмену холста.
- ⚠️ **Ошибка в `loro-codemirror` 0.3.3**: если при создании редактора его текст уже совпадает с документом, первая правка пользователя не доходит до `LoroText` и теряется. Обход — пустая транзакция после микрозадачи плагина (`createNoteEditor`); тест сходимости её ловит.

## Как устроено

| Часть | Что | Где |
|---|---|---|
| Исходник ↔ `LoroText` | BOM и переводы строк — в `meta` при импорте, обратно при экспорте; файл со смешанными переводами строк хранится как есть, редактор делит строки только по `\n` | `source.ts` |
| OFM | Lezer-расширения: `[[цель#заголовок\|псевдоним]]`, `![[…]]`, `==…==`, `%%…%%`, `#тег`, `^id`. Только разбор, текст не переписывается | `ofm.ts` |
| Live preview | Декорации по дереву видимой области: знаки заголовков, выделений, кода, `[[ ]]`, адрес ссылки скрыты вне строки с курсором; у `[[цель\|псевдоним]]` виден псевдоним | `preview.ts` |
| Биндинг | `LoroSyncPlugin` + `LoroUndoPlugin`: 100 шагов, слияние за 1000 мс (10 §9.2) | `editor.ts` |
| Вид | Golos Text для текста, JetBrains Mono для кода (07 §3.2), цвета — токены «Тумана» | `editor.ts` |
| Окно | Двойной клик или `Enter` на заметке; окно у бабла со стороны, где больше места; `Esc` — клавиатура холсту, окно остаётся (06 §13.1) | `NoteWindow.tsx` |
| Хранение в прототипе | Снимок Loro в `localStorage` по ID ноды; у нод демо-сети ID постоянные, заметки переживают перезапуск. В вехе 1A — ядро | `notes.ts` |

## Замеры

| Что | Значение | Бюджет |
|---|---|---|
| Round-trip V-synth, 60 файлов | 60 из 60 побайтно | все (NFR-122) |
| Открытие заметки 1 МБ (T-1M) | 47 мс | ≤ 1 с (NFR-29) |
| Работа на символ в заметке 1 МБ, p95 | 9,6 мс | ≤ 16 мс (NFR-33) |

Задержка «до следующего кадра» в отчёте тоже есть (`keyFrameMs`), но в headless Chromium она равна периоду его vsync — 33 мс при 30 Гц; вердикт — по работе на символ. В сборке на машинах владельца видна настоящая частота.

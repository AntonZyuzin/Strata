# Спайк 11: проверки в запущенном Obsidian

> Пункты 1–5 [13](../13-interop.md) §7.3 отвечает только запущенный Obsidian. Claude подготовил vault и чек-лист, владелец проверяет на macOS и Windows и присылает ответы. Пункт 6 закрыт кодом, пункт 7 — шагом 0.5 ([16](../16-roadmap.md) §3.2). Ответы определяют формат экспорта и повторного импорта (MVP+ 1.2); импорт vault в веху 1C от них не зависит.

## Подготовка (2 минуты)

1. Создать vault: `node docs/spikes/S11-vault/make-vault.mjs ~/Desktop/S11-vault` (нужен Node 18+). Файлы пишет скрипт, а не git: имя в NFD для пункта 4 git на macOS испортил бы.
2. Obsidian → «Open folder as vault» → `S11-vault`. Сторонние плагины не включать.
3. Записать версию Obsidian: «Settings» → «About».

## Проверки (5–10 минут)

| № | Что сделать | Что прислать |
|---|---|---|
| 1 | Открыть `1-canvas/Связи.canvas`, передвинуть карточку «Передвинь меня», закрыть вкладку | Остались ли в файле ключи `"strata"`: у карточек, у ребра и в корне (открыть `.canvas` любым текстовым редактором) |
| 2 | Открыть `2-bases/Tasks.base` | Видны ли обе вкладки: таблица «Все задачи» и «По статусу»; есть ли в таблице «Заметка без статуса» (не должна); работает ли перенос карточки между колонками и что он меняет в файле задачи |
| 3 | Открыть `3-workspace/Открой меня 1` и `Открой меня 2` в двух вкладках, закрыть Obsidian | Файл `.obsidian/workspace.json` целиком или строки с `"file":` |
| 4 | Открыть `4-names/Ссылки` | Куда ведёт `[[Ёлка]]` (файл записан в NFD) и куда — `[[Дубль]]` (два файла в папках `a` и `b`); на Windows — только `[[Дубль]]` |
| 5 | Открыть Graph view | Есть ли линия «Приёмник» — «Источник»: связь только в свойстве `strata-inputs`, в тексте её нет |

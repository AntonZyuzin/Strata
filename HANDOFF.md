Продолжаем Strata — приложение для заметок и проектов на нодах: баблы на холсте, нити между ними, работа с сетью как в Houdini (Tab-меню, вставка в нить, встряхивание, нож), задачи со сроками и ответственными, звёздная 3D-карта. Ретро-пиксельный интерфейс в духе Windows 98 со значками SerenityOS. Стек: Tauri 2, ядро на Rust поверх Loro и SQLite (в браузере — то же ядро в WASM), SPA на React 19 + Vite, холст на Pixi 8. Интерфейс на русском и английском. Весь код пишешь ты; владелец проверяет сборки на macOS (M1) и Windows. Отвечай по-русски. Агентов не запускай без просьбы — владелец просит работать самому.

## Правила владельца по интерфейсу

Их нарушение владелец замечает сразу.

- Максимально функционально, без поясняющих строк: объяснения — только в `title`. Значки вместо текстовых кнопок, меню — по ПКМ, двойной клик — «открыть».
- **Один факт — один раз на экране.** Не повторять имя полем под заголовком, ссылку — ссылкой над полем, заголовок группы — над единственной группой, заголовок страницы — если его уже говорит вкладка.
- **Воздух как в Figma.** Панель: по бокам 16u, сверху и снизу секции 14u, между полями 8u, поля высотой 28u; цвет и значок — блоками на всю ширину, шаг 6u. Плотно прижатое владелец называет «зажатым».
- **Выравнивание.** Элементы в строке: общие верх, низ и середина (логотип, инструменты и вкладки в шапке). Значки в столбце — на одной вертикали (треугольники списков и календари полей). Проверяй замером по пикселям на скриншоте, а не на глаз.
- **Пиксельная графика — только в целое число раз:** значки 16u, 24u (втрое на DPR 2), 32u; шрифт интерфейса 11 px, заголовки — 22 px (ровно ×2). «Чуть меньше» — значит ×1,5 от 16, а не произвольный размер.
- Заголовки панелей — крупные и читаются как заголовки («Ноды» — вдвое крупнее шрифта интерфейса); заголовки секций — обычным регистром цветом текста.
- Один акцент — салатовый. Значки — SerenityOS в духе Windows 98; задача — песочные часы, проект — портфель, папка — папка.
- Каждое изменение UI сначала проверь снимками: RU и EN, DPR 1 и 2. Владелец присылает скриншоты-замечания — отвечай делом и показывай результат.

Сделай каталог со ссылками `chromium_headless_shell-1194/chrome-linux/*` → `/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/*` (плюс `headless_shell` → `chrome-headless-shell`, файл `INSTALLATION_COMPLETE`, `ffmpeg-1011`) и задай `PLAYWRIGHT_BROWSERS_PATH`. WebKit скачать нельзя — он проверяется только в CI.
- Локально в этом Chromium падает e2e «.strata.zip … comes back as a copy» (имя файла `download`); на базовом коммите — так же, в CI проходит. Это не регрессия.

- Тест биндинга доски изредка падает по тайм-ауту под нагрузкой параллельного e2e; отдельно проходит.

## Как работать

- Ядро модели — `docs/05-domain-model.md`. Новое решение сначала меняет модель и оформляется ADR (`docs/adr/`); вопрос — с ID `Q-<док>-<номер>` в документе и в `docs/17-open-questions.md`. Термины — по `docs/glossary.md`.
- Каждое правило модели покрыто тестом (`crates/strata-core/src/tests.rs`); каждое новое окно или панель — e2e-тестом раскладки (RU и EN, DPR 1 и 2, Chromium и WebKit).
- Видимые строки — только через `@strata/i18n`, в оба каталога. Размеры Хрома — в `calc(k * var(--u))`.
- Ассеты — только с источником и лицензией; значки SerenityOS — с того же коммита `e20af912…`, что в `packages/ui/src/icons/serenity/README.md`.
- Коммиты — на английском, Conventional Commits, тело объясняет зачем. Документация — на русском. Скриптовые правки длинных документов проверяй по `git diff --stat`.
- Перед пушем: `cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test`, `pnpm lint && pnpm typecheck && pnpm test`, e2e в Chromium.

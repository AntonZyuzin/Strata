Продолжаем проект Strata: приложение для заметок и проектов на нодах. Баблы в стиле Pathologic, ретро-пиксельный интерфейс, работа с сетью как в Houdini (Tab-меню, вставка в нить, встряхивание, нож), типизированные ноды, MCP, импорт из Obsidian, локальная совместная работа, 3D-карта звёзд. Стек: Tauri 2, ядро на Rust, SPA на React 19 + Vite, Pixi 8, Loro. Интерфейс на RU и EN. Весь код пишешь ты. Владелец проверяет сборки на macOS (MO-mac, M1) и Windows (MO-win). Отвечай по-русски.

**Чему научились (кроме того, что уже есть в CLAUDE.md):**
- Тестовый хук прототипа — `window.__strataProto = { view, graph }`. В e2e точки выбирай через `document.elementFromPoint`: Хром прототипа лежит поверх холста. Прототип открывается на витрине состояний; `?proto&plain` — без фона и с «показать всё», для жестов.
- Программный WebGL (SwiftShader в CI и в headless Chromium) медленный на полноэкранных слоях и на `Graphics`, перестраиваемых в каждом кадре: жест «встряхнуть» (окно 600 мс) ломается первым. Реальную стоимость кадра меряй с GPU: Playwright с `launchOptions.args: ['--use-angle=metal', '--enable-gpu', '--ignore-gpu-blocklist']` на Mac.
- Подсказки в строке состояния прототипа — не длиннее 50 знаков. Ширина колонок строки состояния фиксированная (в `ch`).
- `overflowing(page, scope)` в `e2e/helpers.ts` разрешает обрезать только значение, у которого `title` совпадает с текстом.
- `vite preview` на порту 4173 переиспользуется тестами: после правок пересобери UI (`pnpm build` в `packages/ui`).
- Поиск в Tab-меню (`packages/ui/src/proto/search.ts`) временный. По `09 §2.7` он должен жить в крейте `strata-search` в WASM.
- Каждому новому окну или панели нужен e2e-тест раскладки по матрице `LAYOUTS` (RU и EN). Все строки идут через `@strata/i18n`, в оба каталога.
- После пуша следи за CI; красный CI — твоя работа, а не ожидание. Пуш — отдельной командой `git push origin claude/cool-gates-l1ht77`, без `&&` и `|`: на Mac владельца хук пропускает только такой пуш и только в github.com/AntonZyuzin.
- На Mac владельца нет глобального pnpm: `corepack pnpm`, а для вложенных вызовов — скрипт-обёртка `pnpm` в `PATH`. `gh`, `curl`, `wget` запрещены настройками: статус CI смотри во встроенном браузере (github.com/AntonZyuzin/Strata/actions).
- Для macOS владельцу нужна инструкция, как обойти Gatekeeper у неподписанной сборки: правый клик → «Открыть» или `xattr -dr com.apple.quarantine`.

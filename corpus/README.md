# Корпус форматов

Пространства, какими их записали прошлые версии Gexogon. Каждая следующая версия открывает все записи в CI и читает то же, что читала записавшая (NFR-78, [10](../docs/10-storage-sync-collab.md) §13, [15](../docs/15-architecture.md) §8.2).

## Запись

Папка `<дата>/` — одно пространство в трёх хранилищах и что о нём знала версия:

| Файл | Что | Кто пишет |
|---|---|---|
| `browser.json` | Хранилище браузерной сборки, как его держит IndexedDB (`MemoryStore::to_bytes`): апдейты каждого документа, журнал, ассеты | TS-половина |
| `workspace.strata.zip` | То же пространство архивом ([10](../docs/10-storage-sync-collab.md) §3.5) | TS-половина |
| `content.json` | Что привязки окон читают в документах содержимого: текст и `meta` заметки, пункты списка, элементы, файлы и виджеты доски | TS-половина |
| `folder/` | Папка пространства десктопа: `strata.json`, `store.sqlite`, `assets/`, оставшийся `.lock` — из архива, как его открывает десктоп | Rust-половина |
| `facts.json` | Ответы API на вызовы клиента (дерево, каждая нода, вид каждой сети, нити, корзина, люди, ярлыки, журнал с нодами наборов, ассеты) и значение каждого документа | Rust-половина |

Пространство — V-synth ([14](../docs/14-nfr.md) §1.3), импортированный как vault ([13](../docs/13-interop.md) §3), и сверху всё, что делает пользователь: ноды всех видов, поля задачи, файл и ссылка ассета, цвет, иконка, люди, флаги, размер бабла, стиль нитей, фоны пространства и сети, иконка вида, нити, появление, корзина и возврат из неё, текст с `[[ссылками]]` и призраком, список, виджеты доски, переименование с переписью ссылок, отмена, повтор и откат набора из журнала. Шаги — `packages/backend/src/corpus.test.ts`, функция `makeWorkspace`.

## Проверки

- `crates/strata-core/tests/corpus.rs` — папка (как лежит, через `open_folder` и проверки `strata doctor`), архив и хранилище браузера открываются; ответы API содержат всё, что было в `facts.json` (новая версия может ответить больше, но не меньше; списки сверяются по `id`, а не по порядку), значение каждого документа совпадает точно (пустой корневой контейнер — то же, что нетронутый).
- `packages/backend/src/corpus.test.ts` — документы содержимого из `browser.json` нынешние привязки читают как `content.json`.

## Новая запись

Добавляется при смене формата папки, архива или хранилища браузера, схемы документов, при обновлении Loro или Excalidraw и к сборке каждой вехи. Запись не меняется никогда: если новая версия читает старую запись иначе — это регрессия или миграция, и тогда меняется код чтения, а не корпус.

```sh
pnpm wasm
STRATA_CORPUS_WRITE=2026-11-09 pnpm --filter @strata/backend test corpus       # browser.json, workspace.strata.zip, content.json
STRATA_CORPUS_WRITE=2026-11-09 cargo test -p strata-core --test corpus           # folder/, facts.json
cargo test -p strata-core --test corpus && pnpm --filter @strata/backend test corpus
```

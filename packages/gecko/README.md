# @strata/gecko

Компаньон Strata — пиксельный гекон на холсте пространства ([07](../../docs/07-design-system.md) §10.4). React-компонент без зависимостей, кроме React.

## Происхождение и лицензия

- Рисунок — утверждённый владельцем лист из двенадцати поз (`assets/approved-reference.png`, 2026-10-24), сделан для Strata. Лицензия — лицензия репозитория (AGPL-3.0-or-later), как у своих значков Strata.
- Код перенесён из автономного прототипа владельца (папка вне репозитория, `strata-gecko`, демо `preview.html`) и доведён в Strata: непрерывная деформация на родной пиксельной сетке, перехваты на нити, взаимодействие с нодами, строгие типы.

## Файлы

| Файл | Что |
|---|---|
| `GeckoCompanion.tsx` | React-слой: холст, ввод (клик — погладить, двойной — гулять, перетаскивание, стрелки, Esc), цикл отрисовки, пауза |
| `geckoEngine.ts` | Поведение без DOM: дом, прогулка, очередь реакций с приоритетами, сон, нити и ноды; тесты — `geckoEngine.test.ts` |
| `geckoRig.ts` | Непрерывная сетка исходного рисунка; сгибы лап, опора и перенос, толстый прямой виляющий хвост, три исполнения анимаций, висение хвостом |
| `geckoSprite.ts` | Вырезка поз, сборка кадра на сетке 96×72: подготовка поз и вывод связной сетки с сохранением силуэта внутри холста; без удаления оторвавшихся лап |
| `geckoDeform.ts` | Связная сетка исходных пикселей: сгибы и повороты до растеризации, сохранение соседства пальцев, лап и тела |
| `geckoRotsprite.ts` | RotSprite: поворот пиксель-арта на любой угол (Scale2x ×3, выборка по центрам) |
| `geckoEffects.ts` | Сердечки, плюс, галочка, часы, «Zzz», «?», «!» над геконом |

## Как пользоваться

```tsx
<div style={{ position: 'relative' }}>
  <GeckoCompanion ref={gecko} label={t(locale, 'gecko.label')} hint={t(locale, 'gecko.hint')} />
</div>
gecko.current?.react('task-created');
```

События: `task-created`, `project-created`, `file-created`, `task-completed`, `nodes-linked`, `deadline-near`. В Strata их выбирает `packages/ui/src/workspace/gecko.ts` из шагов графа холста.

В Strata видимые ноды передаются в координатах слоя гекона через `setNodes`, включая движение камеры и перетаскивание нод. Двойной клик отправляет гекона к ближайшей доступной ноде: он ползёт по краю, цепляется хвостом, висит и возвращается. Можно перенести гекона прямо на ноду. Сам компонент также принимает `nodes` и команду `climbNode(id?)`.

Проверка кадров и сценария с реальной нодой — `packages/ui/e2e/gecko.spec.ts`. Привязка всего лица при ползании вниз и висении — `packages/ui/e2e/gecko-anatomy.spec.ts`. Параметр `?geckoReview` включает программный доступ к тому же отрисовщику для проверки всех поз, вариантов, направлений и фаз висения; без параметра этот доступ отсутствует.

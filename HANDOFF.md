## Что это

Strata — приложение для заметок и проектов на нодах: баблы на холсте, нити между ними, работа с сетью как в Houdini (Tab-меню, вставка в нить, встряхивание, нож), задачи со сроками и ответственными, звёздная 3D-карта. Ретро-пиксельный интерфейс в духе Windows 98 со значками SerenityOS. Стек: Tauri 2, ядро на Rust поверх Loro и SQLite (в браузере — то же ядро в WASM), SPA на React 19 + Vite, холст на Pixi 8. Интерфейс на русском и английском. Владелец продукта проверяет сборки на macOS (M1) и Windows.

## Сборка и проверка

Нужны Node ≥ 22 и pnpm 10 (`corepack enable`), Rust 1.97 из `rust-toolchain.toml` с целью `wasm32-unknown-unknown`, `wasm-pack`.

```sh
pnpm install
pnpm wasm                      # ядро и раскладки в WASM: packages/backend/pkg, packages/layout/pkg
pnpm lint && pnpm typecheck && pnpm test
cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test
pnpm --filter @strata/ui e2e   # Playwright; браузеры — pnpm exec playwright install
pnpm dev                       # UI в браузере на ядре-WASM, http://localhost:5173
pnpm desktop:dev               # десктоп
```

- После правки ядра на Rust пересобрать WASM (`pnpm --filter @strata/backend build`), иначе браузер и e2e работают со старым ядром и отвергают новое.
- E2E ходят на `vite preview` порта 4173 и переиспользуют запущенный сервер: после правок UI — `pnpm --filter @strata/ui build`.
- Хук для e2e — `window.__strataWs` (холст, граф, `settled()`), в прототипе — `window.__strataProto`.
- Тест биндинга доски изредка падает по тайм-ауту под нагрузкой параллельного e2e; отдельно проходит.
- Процессы — по PID, не `pkill -f`.

**macOS (машина владельца).**
- `pnpm wasm` падает с системным `ar`: `rustup component add llvm-tools` и `AR_wasm32_unknown_unknown` = `~/.rustup/toolchains/1.97.0-aarch64-apple-darwin/lib/rustlib/aarch64-apple-darwin/bin/llvm-ar`.
- Локальный конфиг e2e с Chromium из кэша Playwright — вне git (`.git/info/exclude`).
- Диск почти полон: `target/` растёт быстро, безопасно освобождать место через `rm -rf target/debug`.

**Облачная сессия (Linux-контейнер).**
- `wasm-pack` нет: готовые бинарники `rustwasm/wasm-pack` v0.13.1 `x86_64-unknown-linux-musl` и `wasm-bindgen` 0.2.129 — в scratchpad и в `PATH`, затем `pnpm wasm`.
- Playwright ждёт Chromium другой сборки, чем лежит в `/opt/pw-browsers`: каталог со ссылками на имеющийся headless shell и `PLAYWRIGHT_BROWSERS_PATH`. WebKit там не скачать — он проверяется в CI.
- Там же падает e2e «.strata.zip … comes back as a copy» (имя файла `download`); в CI проходит — не регрессия.

## Решения владельца по интерфейсу

Владелец назвал прежний UX «абсолютно непонятным»; с тех пор правила такие, и их нарушение он замечает сразу:

- Максимально функционально, без поясняющих строк и лишних элементов: объяснение — только в `title` и меню. Значки вместо текстовых кнопок, меню — по ПКМ, двойной клик — «открыть».
- **Один факт — один раз на экране.** Не повторять имя полем под заголовком, ссылку — ссылкой над полем, заголовок группы — над единственной группой, заголовок страницы — если его уже говорит вкладка. Строку пути и кнопку «Выше» убрали: выход из сети — `U`, где ты — видно в «Нодах».
- Оболочка как Figma или ретро-браузер: главная на весь экран без кнопки закрытия; в шапке логотип (→ главная), импорт, экспорт, отмена, повтор, звёздная карта, вкладки, «+» после последней вкладки, «Настройки» справа. Неактивная вкладка той же формы, только серая.
- «Ноды» — во всю высоту слева, пространство само не строка; панель свойств — во всю высоту справа.
- **Воздух как в Figma.** Панель: по бокам 16u, сверху и снизу секции 14u, между полями 8u, поля высотой 28u; цвет и значок — блоками на всю ширину, шаг 6u. Плотно прижатое владелец называет «зажатым».
- **Выравнивание.** Элементы в строке: общие верх, низ и середина. Значки в столбце — на одной вертикали. Проверять замером по пикселям на скриншоте, а не на глаз.
- **Пиксельная графика — только в целое число раз:** значки 16u, 24u (втрое на DPR 2), 32u; шрифт интерфейса 11 px, заголовки окон — 22 px. «Чуть меньше» — значит ×1,5 от 16, а не произвольный размер.
- Заголовки панелей — крупные и читаются как заголовки; заголовки секций — обычным регистром цветом текста.
- Один акцент — салатовый. Цветная обводка ноды — 6u. Кружки на обоих концах нити, нити — плавные S-кривые.
- Значки — SerenityOS в духе Windows 98; задача — песочные часы, проект — портфель, папка — папка.
- Текст описания в панели не крупнее заголовков, без подсказок-инструкций.
- Каждое изменение UI сначала проверить снимками: RU и EN, DPR 1 и 2. Владелец присылает скриншоты-замечания — отвечать делом и показывать результат.

## Как работать

- Ядро модели — `docs/05-domain-model.md`. Новое решение сначала меняет модель и оформляется ADR (`docs/adr/`); вопрос — с ID `Q-<док>-<номер>` в документе и в `docs/17-open-questions.md`. Термины — строго по `docs/glossary.md`.

- Видимые строки — только через `@strata/i18n`, в оба каталога. Размеры Хрома — в пиксельных единицах `calc(k * var(--u))`.

- Перед пушем: `cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test`, `pnpm lint && pnpm typecheck && pnpm test`, e2e в Chromium.
- Скриптовые правки длинных документов проверять по `wc -l` и `git diff --stat`: однажды замена одной строки обрезала `docs/07-design-system.md` наполовину (восстановлен в `83f0fba`).

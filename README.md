# Strata

Нодовая система для заметок и задач в ретро-пиксельном стиле: типизированные ноды, Houdini-подобная работа с графом, 3D «звёздная карта», MCP, совместимость с Obsidian, локальная работа или свой сервер.

Статус: этап 0 — каркас и спайки ([дорожная карта](docs/16-roadmap.md)). Документация — [docs/README.md](docs/README.md).

## Сборка

Нужны Rust 1.97 (`rust-toolchain.toml`), Node 22 и pnpm 10.

```sh
pnpm install
pnpm dev               # интерфейс в браузере
pnpm desktop:dev       # десктоп-приложение (Tauri 2)
cargo test && pnpm test
```

Готовые сборки для macOS, Windows и Linux — в артефактах последнего запуска CI (вкладка Actions). Сборки пока без подписи Apple и Microsoft, поэтому система предупреждает при первом запуске:

- **macOS.** Перетащить Strata из `.dmg` в «Программы» и попробовать открыть. Затем «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Приложение Strata заблокировано» → «Всё равно открыть» → подтвердить паролем. Если macOS пишет, что приложение «повреждено», выполнить в Терминале `xattr -dr com.apple.quarantine /Applications/Strata.app` и открыть снова.
- **Windows.** Запустить установщик; в окне SmartScreen — «Подробнее» → «Выполнить в любом случае».

Подпись и нотаризация Apple (Developer ID) появятся перед публичным релизом.

## Бенчмарк

В окне «О программе» — кнопка «Бенчмарк». «Запустить» прогоняет холст на 5 и 10 тыс. баблов и движок данных Loro, около трёх минут; окно в это время не сворачивать. У каждой строки результата — ✓ или ✗ по порогу. Потом «Копировать отчёт» — отчёт в буфере обмена в виде JSON. Ноутбук лучше держать на зарядке. Что меряется — [docs/spikes/S1-canvas.md](docs/spikes/S1-canvas.md). В браузере то же открывается по адресу `http://localhost:5173/?bench` после `pnpm dev`.

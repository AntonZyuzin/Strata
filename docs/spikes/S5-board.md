## Кратко

- ✅ **B-2k открывается за 129 мс** (NFR-30: первый кадр ≤ 1 с); **панорама с зумом по всей доске — 60 fps, p95 16,7 мс** (критерий спайка ≤ 16,7 мс). 2 000 элементов, из них 200 картинок со своими файлами; M1, Chromium, ANGLE поверх Metal. Решение — за прогоном в сборке на машинах владельца.
- ✅ **Три клиента сходятся** на 2 000 элементов после случайных правок, удалений и новых элементов в любом порядке обмена; удалённое остаётся надгробием `isDeleted` (`binding.test.ts`).
- ✅ **Окно доски** в прототипе: двойной клик или `Enter` на доске, 80 % холста, тулбар Strata из 10 инструментов, строгий вид — без «дрожи», линии цвета бумаги, Nunito (☑ Q-15-6). Нарисованное и брошенные картинки лежат в документе доски и переживают закрытие окна и перезагрузку (e2e в Chromium и WebKit).
- ✅ **Без сети:** шрифты доски — свои (Nunito и Excalifont с кириллицей, 148 КБ), CDN Excalidraw убран из шрифтов; CSP десктопа (`font-src 'self' data:`) не нарушается.
- ✅ **Excalidraw грузится при первом открытии доски**, а не при старте: его модуль — отдельный чанк.

## Как устроено

| Часть | Что | Где |
|---|---|---|
| Холст | `<Excalidraw ui={false}>` на снапшоте `0.18.0-43a92e6`, светлая тема на прозрачном фоне (туман виден, цвета не инвертируются), `handleKeyboardGlobally={false}` | `BoardCanvas.tsx` |
| Инструмент | `activeTool` под управлением хоста: тулбар Strata — единственный переключатель, инструмент остаётся после использования, как с замком Excalidraw | `BoardCanvas.tsx`, `tools.ts` |
| Элементы | `LoroMap` `elements`: id → JSON элемента целиком. Локально → Loro — элементы из durable-инкремента, если вырос `version`, один коммит на жест. Loro → локально — правило Excalidraw (больший `version`, при равенстве меньший `versionNonce`), элемент под руками пользователя не трогается; более новые локальные элементы пишутся обратно — так сходятся все клиенты | `binding.ts` |
| Картинки | `LoroMap` `files`: id файла → `BinaryFileData` (data URL). ID файла — хеш его байтов, файл неизменен: пишется один раз, сливается по ID | `binding.ts` |
| Шрифты | `EXCALIDRAW_ASSET_PATH` — копия шрифтов в сборке (`vite.config.ts`); источник CDN вырезается из каждого `FontFace` | `assets.ts` |
| Окно | Тулбар слева, сцена справа; пока фокус внутри, клавиши холста выключены; `Esc` вне жеста возвращает клавиатуру холсту | `BoardWindow.tsx` |
| Хранение в прототипе | Снимок Loro в `localStorage` по ID ноды, как у заметок; в вехе 1A — ядро | `notes.ts` |

## Замеры

M1, Chrome for Testing 156 с ANGLE поверх Metal, headless, окно 1440 × 900 @2x, 60 Гц; сценарий `board-b2k` (`?bench&only=board-b2k`).

| Что | Значение | Бюджет |
|---|---|---|
| Открытие B-2k: снимок Loro → второй кадр после готовности Excalidraw | 127–129 мс | ≤ 1 с (NFR-30) |
| Панорама по всей доске с зумом 0,2 → 1 → 0,2, p95 | 16,7 мс, 60 fps, худший кадр 16,8 мс | ≤ 16,7 мс (критерий спайка) |
| Та же панорама при постоянном зуме 1 и 0,3 | 16,7 мс | — |
| Снимок B-2k | 2,4 МБ (200 JPEG по 320 × 240) | — |

Картинки видимой области ≤ 2 с (NFR-30) и память после полного обхода (NFR-52) страница не видит: Excalidraw не отдаёт состояние своего кэша картинок, а память GPU и декодированных картинок не видна JS. Это — проверка владельца в сборке.

## Находки

| Находка | Что было | Решение |
|---|---|---|
| Путь к шрифтам Excalidraw читает при выполнении своего модуля | Модуль был в общем чанке и выполнялся раньше `assets.ts`: все шрифты шли с esm.sh, CSP их блокировала | Холст доски грузится лениво (`React.lazy`), путь ставит вход пакета до загрузки. Заодно Excalidraw ушёл из стартовой загрузки |
| Excalidraw дописывает CDN после нашего пути в каждый `FontFace` | Chromium проверяет по CSP все источники лица при его создании и пишет ошибку на каждый заблокированный, хотя грузит наш файл | Источник CDN вырезается из лиц (`withoutCdn`, тест) |
| Без управления хостом Excalidraw после фигуры возвращается к «Выбору» | Тулбар показывал старый инструмент, а следующие вызовы `setActiveTool` не применялись | `activeTool` под управлением хоста ([API `next`](../research/R5-board-engine.md)) |
| Зум, заданный программно, перестраивает кэш каждого элемента на каждом шаге | Та же панорама с зумом — p95 100 мс, 38 fps | Как в жестах колеса и щипка самого Excalidraw: на время движения камеры `shouldCacheIgnoreZoom`. Любая будущая анимация камеры доски (например, «показать всё») обязана делать так же |
| ID нод демо-сети были случайными | Заметки и доски прототипа терялись при перезагрузке, вопреки [S6](S6-editor.md) | Свой генератор случайной части ID в `seedGraph`, тест: те же ID при каждой загрузке и в обоих языках |
| `onExcalidrawAPI` вызывается с `null` при размонтировании | — | Учтено в типах и коде |

# Передача проекта

Состояние на 2026-10-24, коммит — `git log -1`. Документ для того, кто продолжает работу: человека или новой сессии Claude Code. Правила репозитория, команды и карта кода — в `CLAUDE.md`, он обязателен.

## Что это

Strata — приложение для заметок и проектов на нодах: баблы на холсте, нити между ними, работа с сетью как в Houdini (Tab-меню, вставка в нить, встряхивание, нож), задачи со сроками и ответственными, звёздная 3D-карта. Ретро-пиксельный интерфейс в духе Windows 98. Стек: Tauri 2, ядро на Rust поверх Loro и SQLite, SPA на React 19 + Vite, холст на Pixi 8. Интерфейс на русском и английском. Владелец продукта проверяет сборки на macOS (M1) и Windows.

## Сборка и проверка

Нужны Node ≥ 22 и pnpm 10 (`corepack enable`), Rust 1.97 из `rust-toolchain.toml` с целью `wasm32-unknown-unknown`, `wasm-pack`.

```sh
pnpm install
pnpm wasm                      # ядро и раскладки в WASM: packages/backend/pkg, packages/layout/pkg
pnpm lint && pnpm typecheck && pnpm test
cargo fmt --all && cargo clippy --all-targets -- -D warnings && cargo test
pnpm --filter @strata/ui e2e   # Playwright; браузеры — pnpm exec playwright install
pnpm dev                       # UI в браузере на ядре-WASM, http://localhost:5173
pnpm desktop:dev               # десктоп
```

- На macOS `pnpm wasm` падает с системным `ar`: поставить `rustup component add llvm-tools` и задать `AR_wasm32_unknown_unknown` = путь к `llvm-ar` из тулчейна (`~/.rustup/toolchains/1.97.0-<host>/lib/rustlib/<host>/bin/llvm-ar`).
- E2E ходят на `vite preview` порта 4173 и переиспользуют запущенный сервер: после правок UI — `pnpm --filter @strata/ui build`.
- Хук для e2e — `window.__strataWs` (холст, граф, `settled()`), в прототипе — `window.__strataProto`.

## Ревью изменений 1B (2026-10-24)

Три независимых ревьюера прошли изменения с `407c39a` по `937fdf8` (значки, ADR-0010). Каждое замечание проверено по коду; строки — на момент `937fdf8`. Не ошибка: портфель у проекта — владелец сам выбрал его («тогда проект это портфель, просто замени иконку у задачи»).

**Чинить первыми** (мешают работать):

1. `packages/ui/src/workspace/Inspector.tsx:107` — редактор описания пересоздаётся на каждый рендер `WorkspaceScreen`: эффект зависит от `load`, а `actions.description` — новая функция при каждом рендере. Во время набора теряются фокус и каретка (например, когда истекает тост). Нужна стабильная функция по `details.id`.
2. `Inspector.tsx:80` — `Escape` в полях `Commit` не отменяет, а записывает: `blur()` вызывает `onBlur` со старым `v`. `Escape` в «Новая подзадача» создаёт задачу, в поле ссылки — пишет URL.
3. `packages/backend/src/sync.ts:77` — дуга прогресса задачи и проекта на холсте берётся только при загрузке сети: после галочки, новой подзадачи или нити она не меняется до перехода в другую сеть. Панель («1 из 2») при этом верна.
4. `Inspector.tsx:201` — оптимистичные галочки не сбрасываются: после отмены чеклист показывает галочку, которой в ядре уже нет.
5. `crates/strata-core/src/workspace.rs:1331–1341` — превью-чеклист проекта теряет задачи, замкнутые нитями в цикл, и папку, к которой ведёт нить от задачи (в `wired` попадают цели любого вида). Свёртка их при этом считает. Нужен тест на цикл внутри проекта.
6. `Inspector.tsx:271` — ссылка без схемы («example.com/page») отвергается ядром с ошибкой; дописывать `https://`.
7. `packages/backend/src/core.ts:62` — ассет с файлом без `mime` (все старые картинки «медиа», файлы без типа) на холсте рисуется картинкой, а в панели и «Слоях» считается «файлом».

**Мелочи:**

## Решения владельца по интерфейсу

Владелец назвал прежний UX «абсолютно непонятным»; с тех пор правила такие:

- Максимально функционально, без поясняющих строк и лишних элементов. Объяснение — только во всплывающей подсказке (`title`). Ничего не дублировать: строку пути и кнопку «Выше» убрали, выход из сети — `U`.
- Значки вместо текстовых кнопок, меню — по ПКМ, двойной клик — «открыть».
- Оболочка как Figma или ретро-браузер: главная на весь экран без кнопки закрытия; в шапке логотип (→ главная), импорт, экспорт, отмена, повтор, вкладки, «+» после последней вкладки. Неактивная вкладка той же формы, только серая.
- «Слои» как в Figma: во всю высоту слева, пространство само не строка. Панель свойств — во всю высоту справа.
- Один акцент — салатовый. Цветная обводка ноды — 6u. Кружки на обоих концах нити, нити — плавные S-кривые.
- Значки — SerenityOS в духе Windows 98; задача — песочные часы, проект — портфель, папка — папка.
- Текст описания в панели не крупнее заголовков, без подсказок-инструкций.

## Как работать

- Ядро модели — `docs/05-domain-model.md`. Новое решение сначала меняет модель и оформляется ADR (`docs/adr/`), вопрос — с ID `Q-<док>-<номер>` в документе и в `docs/17-open-questions.md`. Термины — строго по `docs/glossary.md`.
- Каждое правило модели покрыто тестом в `crates/strata-core/src/tests.rs`; каждое новое окно или панель — e2e-тестом раскладки (RU и EN, DPR 1 и 2, Chromium и WebKit).
- Видимые строки — только через `@strata/i18n`, в оба каталога. Размеры Хрома — в пиксельных единицах `calc(k * var(--u))`.
- Ассеты — только с источником и лицензией, всё поставляемое — в «Благодарностях».
- Скриптовые правки длинных документов проверять по `git diff --stat`: однажды замена одной строки обрезала `docs/07-design-system.md` наполовину (восстановлен в `83f0fba`).
